# Шаблон репозитория: Разработка информационной системы

## Описание проекта
Данный репозиторий является стартовым шаблоном для быстрой инициализации проектов. 
**Основное назначение:** Разработка информационной системы по теме **«[Укажите вашу тему здесь]»**.

Шаблон включает в себя заранее настроенную инфраструктуру, процессы обеспечения качества кода и автоматизации, что позволяет команде сразу сосредоточиться на бизнес-логике, а не на настройке окружения.

---

## Технологический стек
* **Язык и платформа:** C# / .NET 10*
* **Хостинг документации / веб-представление:** GitHub Pages
* **CI/CD и автоматизация:** GitHub Actions

---

## Контроль качества кода
В проекте выстроена строгая культура написания кода. Для этого используется следующий стек инструментов:

* **Roslyn-анализаторы** (`SonarAnalyzer`, `Meziantou`) — статический анализ кода, поиск багов, уязвимостей и нарушений best practices на лету.
* **EditorConfig** — обеспечение единого стиля кодирования для всех разработчиков в любой IDE.

**Автоматизация проверок:**
* 🏠 **Локально:** проверки запускаются автоматически перед каждым коммитом благодаря pre-commit хукам на базе **Husky**.
* 🌐 **В CI:** все проверки дублируются в пайплайнах **GitHub Actions**, что гарантирует, что в основную ветку попадет только чистый и безопасный код.

---

## 🌐 GitHub Pages
Проект поддерживает публикацию статического контента (например, документации, отчетов или результатов работы ИС) через **GitHub Pages**. Настройки деплоя интегрированы в GitHub Actions.

---

## 💻 Требования к локальному окружению
Для комфортной работы с шаблоном, запуска проекта и прохождения всех проверок локально, на вашей машине должны быть установлены:

1. **Git** — для работы с системой контроля версий.
2. **.NET SDK** — актуальной версии (совместимой с проектом).
3. **Node.js (и npm)** — необходим для работы пакетных менеджеров и инструмента **Husky** (pre-commit хуки).
4. **IDE** *(Visual Studio / JetBrains Rider / VS Code)* — с поддержкой `.editorconfig` для корректного отображения стилей.
