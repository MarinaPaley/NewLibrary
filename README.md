## Контроль качества кода

Проект использует:
- **CSharpier** для форматирования
- **Roslyn-анализаторы** (SonarAnalyzer, Meziantou) для статического анализа
- **EditorConfig** для единого стиля кода

Все проверки запускаются автоматически:
- Локально через pre-commit хуки (Husky)
- В CI через GitHub Actions
